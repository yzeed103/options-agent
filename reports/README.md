# Reports

Current indicator (`pine/volume_zones.pine`) and its Python counterpart (`vzones/ranges.py`).

| File | What it answers |
|---|---|
| `readings_study.py/.txt` | Do the panel readings carry information? Heading target vs placebo levels, Supertrend flip, trendline break, call/put by noon |
| `volume_support_study.py/.txt` | Does up/down volume or WAE support improve the trend alert / whale bounce |
| `direction_study.py/.md` | Direction-only test of every setup (source of the trend-alert result) |
| `whale_levels.md`, `whale_target_search.md`, `whale_zones.md` | Whale-level research |
| `frvp_match_check.py/.txt`, `profile_resolution_check.py/.txt` | Indicator profile vs TradingView FRVP |
| `trendline_reverse.py/.txt` | How the user's trendline indicator draws its lines |
| `intraday_search.md` | Long search for an intraday strategy (none passed) |
| `make_*.py`, `styles/*.png` | Preview images |
| `archive/` | Results for signals that were removed from the indicator (HUNT, pool break, VA re-entry, rejection) |
